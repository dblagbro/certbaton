# Code of Conduct

## Our commitment

CertBaton contributors, maintainers, and community members commit to making
participation welcoming and free from harassment. We value patient technical
discussion, evidence, respect for different experience levels, and careful
handling of other people's security and operational concerns.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique ideas and changes, not people.
- State assumptions and distinguish evidence from opinion.
- Welcome questions and explain security requirements without ridicule.
- Respect privacy, authorization boundaries, and responsible disclosure.
- Accept a maintainer's request to pause unsafe testing or remove sensitive
  information.
- Give credit and preserve applicable licenses and notices.

## Unacceptable behavior

- Harassment, threats, discrimination, sexualized attention, or personal
  attacks.
- Publishing another person's private information or infrastructure details.
- Pressuring anyone to disclose credentials or run an unsafe production test.
- Deliberately weakening security controls or concealing material risk.
- Sustained disruption, spam, or bad-faith participation.

## Scope

This code applies in project repositories, issue trackers, discussions, review
channels, events, and private project communications. It also applies when an
individual is publicly representing the project.

## Reporting and enforcement

Do not file a public issue containing sensitive conduct-report details. Contact
the repository owner privately using a contact method published on the owner's
GitHub profile and request a private reporting channel. If that is unsafe or
unavailable, use GitHub's platform abuse-reporting process.

Maintainers may edit or remove contributions, comments, commits, or other
material that violates this code, and may temporarily or permanently restrict
participation. Reports will be handled as privately as reasonably possible.
Retaliation against a reporter or witness is itself a violation.
